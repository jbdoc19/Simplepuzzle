# Simplepuzzle

Create small crosswords and download them as Across Lite `.puz` files. Open
`index.html` in a modern browser; no installation or server is required.

Choose a width and height from 1 to 7 and select **Resize grid**. Enter the
solution letters, and use the block tool (or type `#` in a square) to toggle
black squares. Clue numbers update automatically. Fill in each across and
down clue, add any puzzle details, and select **Download .puz**.

Each white square must contain a letter and belong to an answer of at least
two letters. The `.puz` format uses Latin-1 text, so characters such as emoji
and smart quotes must be replaced before downloading. The saved puzzle contains
the solution and an empty grid for the solver.
