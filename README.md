# Simple Puzzle Maker

A single-page app for building mini crosswords (2x2 up to 7x7) and saving them as Across Lite `.puz` files.

- Click a square and type letters; `.` toggles a black square; Space switches Across/Down.
- Clues are numbered automatically; fill them in on the right.
- "Save as .puz" downloads the file (all squares and clues must be filled).

## Run on Replit
Import this GitHub repo into Replit and press **Run** (serves `index.html` with `python3 -m http.server`).
To publish, use Deploy > Static.
